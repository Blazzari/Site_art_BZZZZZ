# Première version — validation visuelle

Une seule page, sept rubriques dans l’ordre validé. Les textes sont centralisés
dans `src/content/portfolio.ts`, les couleurs dans `src/styles/theme.css`, et les
compositions responsive dans `src/styles/portfolio.css`. Les composants partagés
restent limités à la navigation, aux photographies et aux repères de section.

Cinq photographies provisoires proviennent du PDF fourni : deux détails de fleurs
(page 3), le mur (page 5), l’atelier (page 6), les yeux fleuris (page 7).
Images extraites séparément, réduites et encodées en WebP ; aucun montage reconstitué,
aucune image de la chambre intégrée. Les cadrages d’affichage varient avec l’écran.
Les remplacer par les originaux autorisés avant publication définitive.

Police Archivo hébergée localement ; licence OFL conservée dans public/fonts.
Pas de lecteur factice : aucun lien vers le documentaire n’a encore été fourni.
Le bloc BEE reste typographique en attendant une sélection de photographies.
La page conserve noindex et n’est pas destinée à une publication avant validation.
Téléphone, adresse email et identifiant Instagram reprennent le contenu fourni.
